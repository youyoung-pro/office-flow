# 사건 폴더 자동 정리

## 목적
행정사무소의 사건 작업 폴더를 일관된 종류별 구조로 정리한다. 파일은 이동만 하고 삭제하지 않으며(기기에서 삭제 불가), 되돌릴 수 있도록 이동 내역을 보고한다.

## 트리거
- 사용자가 PC 폴더 경로를 지정하고 정리를 요청("이 폴더 정리", "자료실 정리", "종류별로 나눠줘").
- 새 사건 폴더가 개시되어 초기 정리가 필요할 때.

## 전제
- 대상 폴더는 사용자 PC에 있으며 remote-devices 브리지로 접근한다(device_list_dir, device_bash).
- 폴더 접근 권한이 없으면 device_request_folder_access로 요청하거나 사용자에게 데스크톱 앱의 "폴더 추가"를 안내한다.
- 세션 마운트의 실제 경로는 `find /sessions -maxdepth 4 -type d -name "<폴더명>"`으로 안전하게 얻는다(경로에 공백·한글·괄호가 있으므로 반드시 따옴표로 감싼다).

## 절차
1. 현황 파악: device_list_dir를 recursive=true로 호출해 전체 파일을 훑는다. 항목이 2000개를 넘어 잘리면 하위 폴더 단위로 나눠 조사한다.
2. 분류 설계: 아래 표준 분류에 사건 성격을 반영해 카테고리를 확정한다. 필요 없는 분류는 만들지 않는다.
3. 폴더 생성·이동: device_bash로 카테고리 폴더를 mkdir 하고 파일을 mv 한다. rm·rmdir·unlink는 실패하므로 절대 삭제하지 않는다. 각 mv는 실패해도 다음으로 넘어가도록 처리하고(`2>/dev/null`), 이동 후 결과를 ls로 확인한다.
4. 버전 정리: 같은 문서의 v1·v2·최종 등 버전 계열은 최종본 또는 최고 버전만 남기고 나머지는 각 폴더 안의 `_이전버전`으로 옮긴다.
5. 중복 정리: 다른 폴더의 확정본과 중복되는 원본·수집자료는 `_중복(정리전)` 또는 `99. 수집원본(출처별_정리전)`으로 옮긴다.
6. 제출 세트 유지: 라벨이 부착된 증거 묶음(첨부01, 첨부02 …)과 첨부목록은 `00. 첨부(증거자료)_최종`으로 그대로 유지한다.
7. 낱개 파일 정리: 상위에 흩어진 낱개 파일은 해당 종류 폴더로 옮긴다.
8. 보고: 생성한 폴더와 이동한 항목을 요약해 보고하고, 삭제 없이 되돌릴 수 있음을 알린다.

## 표준 분류 (사건 성격에 맞게 가감)
- 00. 첨부(증거자료)_최종 — 라벨 부착 제출용 증거 묶음과 첨부목록
- 10. 사무소_작업문서 — 의견서·검토서·업무계획서·위임계약서·견적서
- 20. 별건(과징금 등) — 사건별 별건 묶음
- 30. 원본_등기·판결·법원 — 등기부·판결문·화해권고·가처분·소송기록
- 40. 원본_계약·취득 — 매매계약서·신고필증·취득세·영수증
- 50번대 — 그 밖의 종류별(무허가·화재, 임대차, 재개발·분양 등)
- 90. 참고·서식·판독 — 판례·서식·판독 이미지
- 99. 수집원본(출처별_정리전) — 출처별 수집 원본과 중복 아카이브

## 안전 규칙
- 삭제 금지(이동만 한다). 확정본과 최신본만 노출한다.
- 이동 내역을 보고하여 언제든 되돌릴 수 있게 한다.
- 제목이 불명확하거나 어느 분류인지 판단이 어려운 파일은 임의로 옮기지 말고 사용자에게 확인한다.
- 한글 등에서 열려 있는 파일은 이동이 거부될 수 있으므로 사용자에게 닫도록 안내한다.
