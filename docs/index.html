행정사사무소 업무 플로우
이식 패키지

유영행정사사무소가 실제로 운영 중인 사건 접수, 수임 확정, 채번, 문서 발급, 폴더 체계, Notion 사건관리 플로우를 귀 사무소의 Claude에 그대로 설치합니다. 무상 공유이며 재판매는 금지됩니다.

설치 (Claude 데스크탑 앱)

1
아래 버튼으로 플러그인 파일을 내려받습니다.
2
Claude 데스크탑 앱의 대화창에 내려받은 파일을 끌어다 놓고 설치를 승인합니다.
3
새 대화에서 사무소 셋업 이라고 입력하면 설치 마법사가 사무소 정보를 물으며 전체 플로우를 세팅합니다.
플러그인 내려받기

설치 (Claude Code)

터미널의 Claude Code에서는 두 명령으로 설치합니다.

/plugin marketplace add kangship/office-flow
/plugin install haengjeongsa-office-flow@youyoung-marketplace

설치 전 준비물

사무소 식별정보(행정사 자격번호, 행정사업무신고번호, 사업자등록번호, 주소·연락처·이메일)와 수임료 입금 계좌를 준비합니다. 계정은 전부 귀 사무소 명의로 자체 준비합니다. Notion 계정, 구글 계정, Claude 유료 계정이 필요하고, 문서 발급 PC에는 한컴 한글과 Python 3.10 이상이 있어야 합니다. 자세한 목록은 설치 마법사가 단계별로 안내하며, 유영행정사사무소의 계정이나 API는 설치 과정에서 일절 사용되지 않습니다.

패키지에 담긴 것

설치 마법사(office-setup-wizard), 상담 접수·수임 확정·사건 개시 스킬(office-case-init), 사건 폴더 정리 스킬(case-folder-organizer), 법정 별지 hwpx 서식 채우기 스킬(hwpx-form-fill), hwp 변환·검수 렌더 스킬(hwp-render-convert), 그리고 채번·문서 생성기 스크립트와 Notion 표준 스키마, 운영 지침 템플릿이 들어 있습니다.
